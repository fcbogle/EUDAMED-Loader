# Workbooks

## Purpose

This tab inventories and profiles the source Excel workbooks as read-only input evidence.

## Current Implementation

- lists source workbooks and sheets
- profiles columns and sample values
- shows normalization visibility for selected fields
- includes the accessories workbook in inventory, but marks it out of scope for active variant mapping

## Current Scope

- active mapping scope:
  - `Echelon`
  - `Elan`
  - `Elite`
  - `Epirus / Esprit`
  - `Navigator / Javelin / Linx`
- excluded from active mapping:
  - `Template for Accessories_Footspares EUDAMED.xlsx`

## Current Output

- workbook inventory
- sheet inventory
- sheet profiles
- distinct-value profiles
- normalization rule visibility
