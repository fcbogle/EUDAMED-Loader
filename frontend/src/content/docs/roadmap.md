# Roadmap

## Near-Term

- reduce field-name drift between canonical models and XML-facing validation/XML paths
- harden workbook parsing against header variation
- keep XML profiles explicit by scenario
- keep documentation aligned to implementation

## Submission Layer

- define explicit submission-domain models
- separate submission assembly from XML rendering helpers
- represent batch manifests and artifacts as first-class objects

## Workflow

- add manual upload workflow support after XML review
- record generated, reviewed, submitted, accepted, and rejected states
- keep audit history compatible with both manual and future automated delivery

## Later

- database persistence
- delivery adapters
- M2M / AS4 integration
